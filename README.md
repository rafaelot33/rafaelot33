### 🚀 Projeto em Destaque

#### Sistema de Agendamento para Barbearia

Sistema de agendamento para barbearia, desenvolvido como projeto real para praticar backend com Node.js, Express e PostgreSQL.

Atualmente o projeto conta com criação de agendamentos, listagem de barbeiros e serviços, controle de status, validação de conflitos de horário, cálculo automático do horário final e listagem de horários disponíveis.

**Status:** Em desenvolvimento  
**Stack:** Node.js, Express, PostgreSQL, HTML, CSS e JavaScript
